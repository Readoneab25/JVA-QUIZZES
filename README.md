# JVA QUIZZES

A collection of independently hostable JAMB JVA practice quizzes for SanctumVault.

## Structure

Each quiz lives in its own folder and uses the reusable quiz architecture based on the GST 112 PRT 7 demo.

```
JVA-QUIZZES/
├── jamb-jva-biology-set-01/
├── jamb-jva-biology-set-02/
├── jamb-jva-biology-set-03/
└── ...
```

### Architecture
- Each quiz is independently hostable.
- Each quiz has its own quiz ID and question set.
- All quizzes use the central SanctumVault results system.
- The GST 112 PRT 7 repository is the demo/template only and is not modified.
