# JVA Medical Standard — Set 01

- **Questions:** 65 (English 20, Physics 15, Chemistry 15, Biology 15)
- **Duration:** 40 minutes
- **Grading:** raw marks out of **65**; no JAMB /400 conversion
- **Mode:** `tutor-review` — scores and answers hidden from students pending authorized staff release
- **Shared bank:** `../jva-standard-65-common/shared-questions.js` — identical English, Physics and Chemistry across the two standards
- **Submission:** uses the existing SanctumVault `submit_quiz_result` RPC with `p_mode: tutor-review`
- **Status:** needs authorized tutor assignment and submission/release smoke test before publishing quiz entry.

The standalone page uses the same student login handoff, navigators, timer, and result release process as the JVA Combined 180 exam.
